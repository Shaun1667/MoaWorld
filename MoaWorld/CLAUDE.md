# MOA WORLD

팰월드의 팰·포획·온라인·오픈월드 요소만 가져온 모작 게임. 귀여운 생명체 '모아'를 포획해 모아가 대신 싸우게 하고, 최대 20명이 한 월드에서 탐험한다. 상세 기획은 `docs/기획서.md`를 먼저 읽는다. 이 파일과 기획서가 어긋나면 기획서가 우선이다.

## 기술 스택

- Unity (2022.3 LTS 이상), C#
- 네트워크: Netcode for GameObjects 호스트 모드. 서버는 호스트 PC가 겸한다(전용 서버 없음)
- 접속: LAN 자동 검색(UDP 브로드캐스트)으로 방 목록을 띄우고 클릭으로 접속한다. 초대 코드, 릴레이, IP 직접 입력은 쓰지 않는다
- 저장: 호스트 PC의 월드 세이브(JSON). 플레이어 고유 ID별로 보유 모아, 코인, 방어구를 기록한다
- 입력은 레거시 Input Manager를 쓴다 (Active Input Handling은 Both)
- 임시 에셋: 모아는 속성 색 캡슐로 대체한다. 3D 모델(glb)은 나중에 교체한다

## 확정된 규칙 (바꾸지 말 것)

### 플레이어
- 플레이어는 직접 공격하지 않는다. 모아가 자동으로 싸운다. 플레이어 레벨은 없다
- 기초 체력 100. 방어구 5종을 사면 체력 증가량이 붙는다: 100, 250, 400, 600, 1000
- 체력 회복: 일정 시간 공격을 받지 않으면 천천히 자동 회복 + 상점 포션 5종(회복량 100, 200, 300, 400, 500)
- 체력 0이면 중앙 마을의 모아 박스 근처에서 부활. 패널티와 아이템 손실 없음
- 한 번에 하나의 대상만 타겟으로 지정할 수 있다

### 모아와 전투
- 스탯은 체력, 공격, 방어 세 가지. 같은 종이어도 개체값이 다르다
- 모아 한 마리당 스킬은 하나. 모아를 꺼낸 상태에서 ① 누군가 플레이어와 전투 상태이거나 ② 플레이어가 타겟을 지정하면, 쿨타임마다 자동으로 스킬을 쓴다
- 속성은 물, 불, 풀, 노말 네 가지. 물 > 불 > 풀 > 물 순환 상성. 노말은 상성 없음
- 모아가 기절하면 전투에 꺼낼 수 없고, 모아 박스에서 회복시킨 뒤에야 꺼낼 수 있다
- 경험치는 결정타를 날린 모아가 받고, 코인은 먼저 줍는 사람이 가져간다
- 플레이어끼리 전투(PvP) 가능. 패배 패널티 없음, 안전지대 없음

### 포획
- 모아볼로 포획한다. 포획 권한은 먼저 모아볼을 던진 플레이어
- 이미 주인이 있는 모아는 포획할 수 없다
- 체력이 가득 찬 약한 모아도 낮은 확률로 잡을 수 있다(첫 모아 포획 방법)
- 시작 지급: 모아를 한 마리도 잡지 않았고 모아볼도 없는 플레이어에게 모아볼 5개
- 코인은 야생 모아가 쓰러진 자리에 떨어지고, 15분 뒤에 사라진다

### 파티와 모아 박스
- 맵 중앙에 파괴할 수 없는 모아 박스 1개, 그 근처에 상점. 보관함은 플레이어마다 개인 소유
- 파티는 최대 6마리. 박스는 한 페이지 30마리, 30페이지(플레이어당 최대 900마리)
- 파티가 가득 차면 포획한 모아는 자동으로 박스에 보관된다
- 박스에 넣어둔 모아는 10분 뒤에 체력이 모두 회복된다(별도 회복기 없음)

### 월드
- 낮밤은 15분 주기. 낮밤에 따라 출현하는 모아가 달라진다(세부는 나중에)
- 최대 20명. 전투와 포획 판정은 호스트가 수행한다
- 제외 요소: 생존, 건축, 자동화, 탈것과 수영 등 이동 수단, 필드 상자, 던전, 날씨, 보스

## 모아 21종과 속성

| 속성 | 종 |
|---|---|
| 풀 | 토끼, 노루, 반달가슴곰 |
| 불 | 삵, 오소리, 붉은여우, 호랑이 |
| 물 | 수달, 금개구리, 멧돼지 |
| 노말 | 고라니, 호랑나비, 다람쥐, 참매, 수리부엉이, 두루미, 까치, 뒤영벌, 고슴도치, 구렁이, 담비 |

## 프로토타입 범위

코어 루프 + LAN 멀티플레이를 구현한다.

- 이동, 야생 모아 스폰, 타겟 지정, 모아 소환과 자동 전투, 모아볼 포획
- 파티 6마리, 모아 박스(보관·꺼내기·10분 회복), 코인 드랍과 소멸, 상점(모아볼·방어구·포션)
- 호스트 방 열기, LAN 방 목록과 접속, 월드 세이브와 불러오기
- 낮밤 주기, HP 표시

## 아직 정해지지 않은 값

아래는 임시값을 쓰되, 한곳(`GameConfig` 등)에 모아 쉽게 바꿀 수 있게 만든다. 값을 하드코딩하지 않는다.

- 가격: 모아볼, 방어구 5종, 포션 5종
- 포획 확률 공식과 체력 가득 찬 모아의 포획 확률
- 모아 레벨 상한, 경험치 공식, 개체값 범위, 21종의 체력·공격·방어·스킬 수치, 상성 배율
- 야생 모아의 선공 여부, 추적 범위, 다시 나타나는 시간, 코인 획득량
- 자동 회복이 시작되는 시간과 속도
- 방어구 체력은 가장 높은 것 하나만 적용한다고 가정한다(누적 여부 미확정)

나중으로 미룬 항목: 맵 배치, 희귀 모아 스폰 조건과 확률, 공격 모션과 리깅, 모아 교환 기능, 플랫폼(PC 한정 여부).

## 작업 규칙

- 기획서에 없는 규칙을 만들어 넣지 않는다. 필요하면 임시값으로 두고 어떤 가정을 했는지 알려준다
- 코드와 주석, 변수명은 영어, 화면에 표시하는 글자는 한국어
- 서버(호스트) 권한 방식으로 만든다. 데미지, 포획, 코인, 구매는 서버에서만 판정한다
- 큰 기능은 한 번에 만들지 말고 코어 루프부터 순서대로 만들어 직접 확인할 수 있게 한다
