# MOA WORLD 기획서 2차본

2026-10-07 · @남귀훈

## 한줄 소개와 확정 사항

귀여운 생명체 '모아'를 발견하고 포획해 함께 싸우며, 최대 20명이 한 월드에서 탐험하는 온라인 오픈월드 게임.

| 항목 | 확정 내용 |
|---|---|
| 전투 | 모아가 자동으로 싸운다. 플레이어는 직접 공격하지 않는다 |
| 포획 도구 | 모아볼. 포획 권한은 먼저 모아볼을 던진 사람 |
| 재화 | 야생 모아가 쓰러진 자리에 모아 코인이 떨어지고 먼저 줍는 사람이 가져가며, 상점에서 모아볼을 산다 |
| 성장 | 플레이어 레벨 없음. 플레이어 기초 체력은 100이고 상점에서 방어구를 사면 체력이 늘어난다. 모아 레벨만 있고, 전투에서 상대를 쓰러트리면 경험치를 얻는다 |
| 최종 목표 | 특별한 엔딩 없이, 모든 모아를 포획하는 것 |
| 온라인 | 호스트 PC가 서버를 열고, 최대 20명 접속. 개발 엔진은 Unity |
| 거점 | 맵 중앙의 모아 박스와 그 근처의 상점 |
| 제외 요소 | 생존, 건축, 자동화, 탈것·수영 등 이동 수단, 필드 상자, 던전 |

## 핵심 루프

플레이어는 직접 싸우지 않고, 모아가 전투하고 플레이어는 모아볼을 던진다. 모아 코인으로 모아볼을 사며 루프가 이어진다.

1. 지역을 탐험하며 야생 모아를 발견한다
2. 내 모아가 야생 모아와 전투해 쓰러트린다 (결정타를 날린 사람이 경험치, 코인은 먼저 줍는 사람)
3. 모아볼을 던져 포획하고 도감에 기록한다 (먼저 던진 사람이 포획 권한)
4. 모아 코인으로 상점에서 모아볼을 사고, 모아 박스에서 모아를 회복·편성한다
5. 더 강한 모아가 사는 지역으로 나아가며 모든 모아를 포획해 도감을 완성한다

## 모아와 전투 시스템

전투는 모아끼리 벌어진다. 플레이어 자신은 전투에 참여하지 않고, 모아를 내보내 싸우게 한 뒤 모아볼을 던지는 역할을 한다.

| 영역 | 내용 |
|---|---|
| 전투 주체 | 모아. 플레이어는 탈것·수영 등으로도 모아를 쓰지 않는다 |
| 파티 | 모아 여러 마리를 편성해 들고 다니고, 필요할 때 소환한다 |
| 승리와 경험치 | 상대를 쓰러트린 모아가 경험치를 얻는다 |
| 모아 레벨 | 플레이어 레벨은 없고 모아 레벨만 있다. 레벨 성장 구조는 모아 종마다 다르다 |
| 개체값 | 스탯은 체력, 공격, 방어 세 가지다. 같은 종이어도 개체마다 개체값이 다르다 |
| 스킬 | 모아 한 마리당 스킬은 하나다 (우선 이 단계에서는 하나로 고정) |
| 포획 방식 | 야생 모아의 체력을 줄인 뒤 모아볼을 던져 잡는다. 체력이 가득 찬 약한 모아도 낮은 확률로 잡을 수 있다 (첫 모아 포획 방법) |
| 포획 권한 | 먼저 모아볼을 던진 플레이어에게 주어진다 |
| 희귀 모아 | 포획이 어렵고 강하다. 특정 시간대에만 등장하는 모아도 있다 |

**전투 조작:** 모아를 꺼낸 상태에서 ① 누군가 플레이어와 전투 상태이거나 ② 플레이어가 누군가를 타겟으로 지목하면, 모아가 각 스킬의 쿨타임마다 자동으로 스킬을 사용한다.

**플레이어 체력:** 기초 체력은 100이고, 상점에서 방어구를 사면 체력이 늘어난다.

**속성과 상성:** 속성은 물, 불, 풀, 노말 네 가지만 정해둔다. 노말은 상성이 없다.

| 공격 속성 | 유리한 상대 |
|---|---|
| 물 | 불 |
| 불 | 풀 |
| 풀 | 물 |
| 노말 | 없음 (무상성) |

**야생 모아 행동:** 모아마다 다르게 설정한다. 플레이어를 먼저 공격하는 모아(선공)와 먼저 공격하지 않는 모아가 있다.

**보상 분배:** 야생 모아가 쓰러지면 그 자리에 모아 코인이 떨어지고, 먼저 줍는 사람이 가져간다. 경험치는 마지막 결정타를 날린 사람이 받는다.

**플레이어 간 전투:** 플레이어끼리도 전투할 수 있다.

**PvP 세부 규칙:** 플레이어끼리 싸워서 져도 패널티는 없다. 이미 주인이 있는 모아는 포획할 수 없고, 안전지대는 두지 않는다.

**타겟 지정:** 한 번에 하나의 대상만 타겟으로 지정할 수 있다.

**플레이어 체력 회복:** 일정 시간 공격을 받지 않으면 체력이 천천히 자동 회복되고, 상점에서 파는 포션(회복량 100·200·300·400·500의 5종)으로도 회복한다.

**플레이어 쓰러짐:** 플레이어 체력이 0이 되면 중앙 마을의 모아 박스 근처에서 부활한다. 패널티와 아이템 손실은 없다.

**지역 난이도:** 지역별 난이도는 야생 모아들의 레벨로 결정한다.

모아가 기절하면 전투에 꺼낼 수 없고, 모아 박스에서 회복시킨 뒤에야 다시 꺼낼 수 있다.

## 모아볼과 모아 코인, 상점

포획 도구는 모아볼 하나이고, 모아볼은 모아 코인으로 상점에서 산다. 제작 시스템은 없다.

| 항목 | 내용 |
|---|---|
| 포획 도구 | 모아볼 |
| 시작 지급 | 모아를 한 마리도 잡지 않았고 포획 도구도 없는 플레이어에게 모아볼 5개를 지급한다 |
| 모아 코인 | 야생 모아가 쓰러진 자리에 떨어진다. 먼저 줍는 사람이 가져간다 |
| 상점 | 맵 중앙 근처에 배치한다. 모아 코인으로 모아볼과 방어구를 산다. 방어구를 사면 플레이어 체력이 늘어난다 |
| 방어구 | 5종. 체력 증가량은 100, 250, 400, 600, 1000이다 |
| 포션 | 5종. 플레이어 체력을 100, 200, 300, 400, 500 회복한다 |
| 코인 소멸 | 떨어진 모아 코인은 15분 뒤에 사라진다 |

## 모아 박스 (맵 중앙 오브젝트)

건축을 넣지 않으므로, 팰월드의 팰 박스 역할을 하는 '모아 박스'를 맵 중앙에 고정 배치한다. 플레이어는 직접 짓지 않고 이 오브젝트를 이용한다.

| 항목 | 제안 내용 |
|---|---|
| 위치 | 맵 중앙에 1개 고정. 시작 지점 역할도 겸한다 |
| 보관 | 포획한 모아를 모아 박스에 맡기고 꺼낼 수 있다. 파티 편성도 여기서 한다 |
| 포획 초과분 | 파티가 가득 찼을 때 포획한 모아는 자동으로 박스에 보관된다 |
| 회복 | 모아 박스에 넣어둔 모아는 10분 뒤에 체력이 모두 회복된다. 별도의 회복기는 두지 않는다 |
| 개별 사용 | 20명이 한 오브젝트를 쓰므로, 보관함은 플레이어마다 개인으로 분리한다 |
| 파괴 여부 | 파괴할 수 없는 오브젝트로 둔다 |
| 파티 | 플레이어당 최대 6마리를 데리고 다닌다 |
| 보관 용량 | 한 페이지에 30마리씩, 30페이지(플레이어당 최대 900마리) |

## 온라인 구조

호스트 플레이어의 PC가 서버를 열고, 최대 20명이 접속해 한 월드를 공유한다. 아래 규칙은 이 방식에서 반드시 정해야 하는 것들의 제안이다.

| 항목 | 제안 내용 |
|---|---|
| 접속 방식 | 호스트가 서버를 열면 같은 네트워크(LAN)의 참가자 화면에 방 목록이 자동으로 뜨고, 클릭만으로 접속한다 (초대 코드 없음) |
| 최대 인원 | 20명 |
| 월드 저장 | 월드 데이터는 호스트 PC에 저장한다 |
| 모아 소유권 | 플레이어가 잡은 모아는 그 플레이어 개인 소유로 월드에 저장된다 |
| 호스트 종료 시 | 방이 닫히고, 다시 열면 저장된 진행이 이어진다 |
| 모아 교환 | 미정 (넣을지 여부를 아직 정하지 않았다) |
| 부정 행위 방지 | 전투·포획 판정은 호스트가 수행한다 |
| 플레이어 데이터 저장 | 확정: 호스트 PC에 저장한다. 플레이어 고유 ID별로 보유 모아, 코인, 방어구를 월드 세이브에 함께 기록한다 |
| 네트워크 방식 (추천) | Unity Netcode for GameObjects의 호스트 모드와 LAN 자동 검색을 함께 쓴다. 공식 패키지라 유지보수가 안정적이고, UDP 브로드캐스트로 같은 네트워크의 방을 자동으로 찾아 포트포워딩 없이 접속되며 20명 규모의 자동 전투 게임에 충분하다. 대안은 Mirror(무료, 자료가 많음)다 |

이 방식의 한계도 알아두어야 한다. 20명 접속은 호스트 PC에 부담이 크고, 실시간 전투에서는 호스트 회선이 좋지 않으면 모두가 렉을 겪는다. 작은 모아가 많이 나오는 맵일수록 더 그렇다. 포트 포워딩 없이 접속하려면 Steam 릴레이 같은 중계 서비스를 쓰는 방법도 있다.

## 오픈월드와 도감

숲, 초원, 사막, 설원 등 환경이 다른 지역을 자유롭게 다니고, 지역마다 다른 모아가 등장한다.

- **출현 조건:** 지역과 시간대에 따라 다른 모아가 나타난다. 특정 시간대에만 나오는 모아는 희귀 모아로 둔다.
- **낮밤 주기:** 낮과 밤이 15분마다 바뀐다.
- **지역 난이도:** 지역마다 모아의 강도가 다르다.
- **도감:** 발견한 모아와 포획한 모아를 기록하고, 서식 지역과 특징을 확인할 수 있다. 도감은 플레이어 개인 기록이다. 모든 모아를 포획해 도감을 채우는 것이 최종 목표다.
- **이번 단계에서 제외:** 필드 상자, 던전, 이동 수단.
- **맵 크기와 지역 해금:** 아직 정해지지 않았다 (미정 사항 참고).

## 팰월드와의 차별화

생존, 건축, 자동화는 빼고 탐험·전투·수집에 집중한다. 이번 프로젝트는 팰월드를 모작하는 것이 목표이므로 전투·포획·팰 박스 역할을 팰월드와 동일한 방식으로 가져간다.

다른 게임과의 차별화는 모작이 완성된 뒤에 정한다. 후보는 귀여운 모아, 희귀 모아 협동 탐색, 시간·날씨 한정 모아이다.
